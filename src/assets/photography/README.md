# Photography assets

Drop your photo files (`.jpg`, `.jpeg`, `.png`, `.webp`) directly into this folder.
They'll automatically show up in the gallery on the Photography page —
no code changes needed.

Tips:
- Use descriptive filenames (e.g. `sunset-north-atlantic.jpg`) — the filename
  becomes the caption (dashes/underscores are turned into spaces).
- Keep images reasonably sized (under ~5MB each) for fast page loads.
